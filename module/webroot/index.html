About

File Hider hides selected paths from selected apps only. It never touches system_server.

App names and icons come from the manager bridge when available; otherwise the package name and a generated monogram are used.

Guide

Help & setup

What File Hider does, how to configure it safely, and what it cannot cover.

1 How it works

File Hider is a Zygisk module. When a selected app starts, the module hooks file access in that process only. The app receives ENOENT for selected paths, and directory listings omit those entries. Other apps keep seeing the real filesystem.

  • Works across Java, native, stat/open/access, and directory enumeration.
  • Shell children get an exact hidden path rewritten to a missing decoy path.
  • Rules are read when a target process spawns. Restart the app after saving.

2 Add an app

Tap an app on the home screen. Add absolute paths with the input, the file browser, or a common-path preset. Tap Save, then use Save & force-stop or force-stop the app yourself before opening it again.

The checkbox on the home screen means active. Turning it off keeps the app's paths in the config but writes an !package marker, so the native module skips that app. Turn it back on to restore hiding without re-entering paths.

3 Choose paths

Use the categories: Integrity, Root traces, Emulator, Native & maps, System libraries, and Other. Tap a category to expand it. Risky presets are inside Advanced and ask for confirmation.

  • /proc/cpuinfo, /proc/stat, and build props are usually safe.
  • Danger: hiding /system/lib or /system/lib64 can stop an app from loading native libraries.
  • Danger: hiding /proc/self/maps can break ART, profiling, and crash reporting.
  • Danger: hiding /proc/self/mountinfo can hide real mount checks but may break unrelated probes.

4 Verify

Save the rule, force-stop the app, then open it again. Open Diagnostics and look for target=, hooks active, and first blocked path. If the app still sees the path, it may use a raw syscall, a shell command that builds the path internally, or an unlisted alias.

5 Limitations

  • Raw syscalls bypass the libc hooks.
  • Shell children do not inherit hooks; only an exact hidden path in a command or argv is rewritten.
  • Mount namespaces, bind mounts, and paths assembled only inside a child process are not covered.
  • App labels/icons require manager support; otherwise this page falls back to package names and monograms.
  • This is not a universal integrity fix. Use the right tool for mount/namespace-level hiding.
